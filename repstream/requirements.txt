# RepStream — the single dependency file for the whole project.
#
# Covers BOTH applications, which share one virtualenv (repstream/venv):
#   backend/                the RepStream API
#   backend/ai_assistant/   the Datastream chatbot
#
# They previously had separate requirements files whose pins conflicted on every
# shared package — the backend pinned each one just below the chatbot's floor
# (fastapi 0.115.5 vs >=0.115.6, pydantic 2.10.3 vs >=2.11, scikit-learn 1.5.2
# vs >=1.8, pyodbc 5.2.0 vs >=5.3, openai 1.57.4 vs >=1.58.1). No single
# environment could satisfy both, which is why there were two venvs.
#
# Resolved by taking the higher floor in every case: the chatbot's minimums are
# newer, and nothing in the backend needs an older release. Shared packages are
# therefore >= rather than ==, so one install serves both.
#
#   python -m venv venv
#   venv\Scripts\activate
#   pip install -r requirements.txt
